## Tooling traps on the owner's Mac (learned the hard way)

- Backgrounded `./gradlew` runs get killed silently by the shell harness.
  Run gradle detached: `sh -c 'nohup ./gradlew <task> > /tmp/x.log 2>&1 &'`
  and poll the log for `BUILD SUCCESSFUL|BUILD FAILED`.
- Never trust an exit code that passed through a pipe (`| tail`) — read the
  log. Gradle's cache and `rtk` can both dress a failure as success; a
  "BUILD SUCCESSFUL in 8s" is only believable after checking the test task
  executed and counting result XMLs in
  `android/app/build/test-results/testDebugUnitTest/`.
- A hung suite is usually a deleted-pipeline test blocking in `runBlocking`
  on a frame the codec now rejects — jstack the Gradle Test Executor to
  find it; don't wait it out.
- A locked Pixel fails the connected suite — check the keyguard before
  blaming a test.
- Go: use `go test -count=1 -p 1 ./companion/...` for a trustworthy full
  matrix on this branch.
