# TikTok Agentic Arch resume plan

```text
ml_base.pdf + Agentic Arch job description
                 |
                 v
       extract facts and target terms
                 |
                 v
       role-specific resume copy/layout
                 |
                 v
Downloads/TikTok Agentic Arch resume.pdf
                 |
                 v
        text, page-count, and visual QA
```

## Done means

- The supplied `ml_base.pdf` remains the factual source of the resume.
- The copy foregrounds verified evidence for agents, program synthesis, formal verification, evaluation, tool/environment interaction, multi-agent systems, observability, and production impact where those facts are already present.
- No new numbers, employers, technologies, publications, or availability claims are invented.
- The result is a readable one-page PDF in the user's Downloads folder.
- The final PDF has selectable text and is checked against the job description and rendered visually.

## Execution

1. Inspect the existing resume renderer and any matching profile data.
2. Build a separate Agentic Arch-targeted source from the supplied resume facts.
3. Render the PDF to Downloads.
4. Verify page count, extracted text, expected sections/keywords, and visual layout.
5. Have an independent reviewer check factual fidelity, job match, ATS readability, and presentation.

## Assumptions

- The output is a targeted resume, not an application submission.
- The base PDF's one-page constraint is retained.
- Availability and work-authorization statements are omitted unless already stated in the supplied resume, rather than guessed.
