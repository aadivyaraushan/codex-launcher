# X post screenshot set

Date: 2026-07-15

## Purpose

Four screenshots that explain the Codex Launcher UI in one X carousel. These
are 1080 x 2424 Android VM captures of the implemented Compose UI. They use
fixed synthetic sample content and contain no pairing links, local task data,
or private computer details.

## Recommended order

1. `outputs/android-vm-audit/state-home_online.png` - launcher home, task states,
   project/model controls, prompt composer, apps, and Android settings.
2. `outputs/android-vm-audit/state-task_transcript.png` - mobile Codex transcript,
   reasoning, plan, command result, and changed-file activity.
3. `outputs/android-vm-audit/state-approval_full.png` - an approval request with
   working folder, reason, access level, affected paths, and scoped choices.
4. `outputs/android-vm-audit/state-apps.png` - the deliberately minimal app
   drawer and launcher settings entry point.
