Codex Launcher / approved visual system / 2026.07.12

One quiet instrument. Two modes.

Deep Charcoal and Warm Paper are now one interface, not competing directions. The launcher follows Android's light or dark setting by default, with persistent manual overrides. Each phone uses a 412 × 892 visual canvas with explicit top and bottom system insets; implementation must bind to the device's reported safe areas.

“My phone is a quiet interface to my work, not a grid of apps.”
Hermes: flat task surface and live tool state Niagara: one-handed vertical scanning Olauncher: words before icons Codex Remote: host, task, approval, result
Invariant 01

Tasks replace favorites

The launcher opens on active work. Ordinary apps remain one upward gesture away through a searchable text list.

Invariant 02

State is written, not implied

Online, working, waiting, approval, and offline states use words and shape as well as color.

Invariant 03

The escape route always works

Apps and Android Settings remain reachable even when the computer connection is unavailable.
